## ✈️ Dimaak Travel Tech

### Travel Technology Platform

Worked on the modernization of a large travel technology platform
covering **4,000+ destinations**.

The existing platform was based on legacy HTML and jQuery with
repeated hard-coded JSON-driven pages.

### Platform Modernization

- Migrated the legacy HTML / jQuery experience to **Next.js**
- Replaced repeated hard-coded pages with a
  **configuration-driven page architecture**
- Built reusable page structures driven by configuration
- Implemented **server-side rendering**
- Supported more than **4,000 destination pages**
- Worked on the overall frontend revamp
- Contributed to improvements in conversion performance

### Architecture

The configuration-driven approach allowed destination pages to be
generated from structured configuration instead of maintaining
separate implementations for every destination.

# 🏗️ How I Approach Frontend Engineering

I enjoy solving frontend problems at the intersection of
**product complexity, scalability and user experience**.

### ⚙️ Configuration-Driven Systems

Turning repeated UI implementations into reusable systems driven by
configuration.

I've applied this approach to both large-scale travel pages and
complex banking forms.

### 🌍 Large-Scale SSR & SEO

Building server-rendered experiences capable of generating thousands
of crawlable pages while keeping URL structures and page rendering
SEO-friendly.

### 🧩 Micro-Frontend Architecture

Working across independently maintained applications and integrating
them into a unified product ecosystem.

### 🏦 Complex Business Workflows

Building interfaces for banking, financial products, hotel
operations, travel, education and collaboration workflows where
different business rules result in different UI flows.

### 🎨 Design Systems

Building reusable component libraries and documenting components
through Storybook to maintain consistency across applications.

### ⚡ Performance

Working with rendering strategies, data fetching, state management,
component architecture and Core Web Vitals to improve frontend
performance and user experience.

### ♿ Accessibility

Considering WCAG compliance and accessible interaction patterns while
building reusable UI systems.
